# Benchmark results

One folder per measuring session: `<yyyy-mm-dd>-<machine>/` (a second session of the day appends `-<build>`),
containing the files `/mobium bench` wrote to `<game dir>/mobium-bench/` (the per-run CSVs and `summary.csv`) and a
short `setup.md` with the machine, driver, graphics preset, shader pack and resource pack versions. The protocol is in
`docs/benchmarks.md`.
